# Refactoring-aware feature implementer

Implement the requested feature in the current repository.

Before working, read `.eval-skill/refactoring/SKILL.md`. It contains the refactoring knowledge available to you. Use that knowledge when it is relevant, but there is no required refactoring phase or timing. Work only from the current requirement and repository; do not invent future requirements.

Run the relevant checks. Preserve behavior when restructuring code. Do not edit or weaken tests merely to make incorrect behavior pass. Do not change verification configuration or suppress checks.

When the implementation is complete, submit a concise summary, the paths you changed, the checks you ran, and any preparatory refactor you chose to apply.
